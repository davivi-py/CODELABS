🐾 ONG CodeLab — Site de Adoção de Animais

Site desenvolvido para conectar animais disponíveis para adoção com possíveis adotantes, com cadastro, busca por filtros e página de detalhes de cada animal.

Funcionalidades:

-Login e autenticação de usuários
-Cadastro de animais com upload de foto
-Listagem com filtros (espécie, porte, sexo, idade)
-Busca por nome em tempo real
-Página de detalhes de cada animal

Stacks usadas:

Front-end: HTML, CSS, JavaScript
Back-end: Supabase (autenticação, banco de dados e armazenamento de imagens)


Projeto desenvolvido por Clara, Davi e Mare como parte do processo de admissão no CodeLabs — USP São Carlos.
